# EduStream Mobile — Architecture

Repo: https://github.com/shoaibhajj/EduStream-mobile.git

## Stack

| Layer | Technology | Notes |
|---|---|---|
| Framework | Expo (managed workflow) | Latest stable Expo SDK |
| Navigation | Expo Router | File-based routing |
| Auth | `@clerk/clerk-expo` | Mobile auth |
| Database | Supabase | Shared backend with web |
| Storage | Supabase Storage + Cloudinary | Thumbnails in Supabase, lesson videos in Cloudinary |
| Video playback | `expo-av` + `react-native-webview` | Native player + embed fallback |
| Styling | NativeWind | Tailwind-style utility classes |
| Secure local storage | `expo-secure-store` | Clerk token cache |
| Language | TypeScript strict | No `any` |

## Standalone Repo Rule

This repo is fully standalone. It has its own dependencies, its own configuration, and its own lifecycle. It must never import code from the web repo. Shared behavior between mobile and web is shared through the cloud backend only, not through code.

## Backend Model

- Mobile connects directly to Supabase using the anon key.
- Row Level Security protects private data.
- Mobile never uses a service-role key.
- Signed Cloudinary lesson URLs are generated by a Supabase Edge Function, not inside the app.

## Data Access Rules

- Students can watch a lesson only if it is a free preview or if they have a confirmed enrollment.
- Teachers can only manage their own courses and lessons.
- Empty years and subjects must be filtered at query level.

## Invariants

1. Never put Cloudinary secrets in the mobile app.
2. Never use the service-role key in mobile.
3. Use `npx expo install` for native Expo packages.
4. Keep mobile logic independent from the web repo.
